## 岗位信息

- 岗位编号：fe-001
- 所属部门：智能应用研发部
- 工作地点：上海（不支持远程）
- 招聘人数：1 人
- 汇报对象：前端负责人
- 到岗时间：一个月内到岗

## 岗位职责

1. 负责 AI 应用（智能问答、简历筛选工作台）的前端架构设计与核心模块开发；
2. 与算法团队协作，落地大模型流式输出、多轮对话、工具调用等交互形态；
3. 沉淀组件库与工程规范，推动团队交付效率提升；
4. 参与需求评审，与产品、后端共同拆解技术方案并评估工期。

## 任职要求

1. 学历：大专及以上，计算机相关专业优先；
2. 经验：5 年以上前端开发经验，其中 2 年以上 Vue3 + TypeScript 项目经验；
3. 技术栈：精通 Vue3（Composition API）、TypeScript、Vite，熟悉 Pinia 与 Vue Router；
4. 大模型相关：有 SSE / WebSocket 流式渲染、Markdown 增量渲染、对话上下文管理的实际经验；
5. 工程能力：有组件库封装经验（TDesign / Element Plus 均可），能独立设计可复用的业务组件；
6. 协作：能与算法、后端团队对接接口协议，具备把模糊需求拆成技术方案的能力。

## 加分项

1. 有 RAG、Agent、Prompt 工程的实践经验；
2. 有 Node.js / BFF 层开发经验，能独立完成接口联调与鉴权；
3. 有前端性能优化与监控（埋点、错误上报）的落地经验；
4. 有跨端（uni-app / 小程序）交付经验；
5. 有大型遗留系统重构经验（例如 JSP / Vue2 迁移到 Vue3）。

## 面试流程

1. 技术一面：项目深挖 + 手写题（60 分钟）；
2. 技术二面：架构设计 + 大模型交互方案设计（60 分钟）；
3. HR 面：意向与薪资沟通（30 分钟）。
