## 第一条　缔约主体与定义

1.1 **缔约主体**：本协议由 {{甲方名称}}（下称「甲方」）与 {{乙方名称}}（下称「乙方」）
就 {{产品名}}（下称「本产品」）的私有化部署与使用事宜订立。双方主体信息、地址与联系方式
见签署页或另行以 `{{地址}}`、`{{联系邮箱}}`、`{{联系电话}}` 填列。

1.2 **定义**（本协议中下列词语含义如下，具体表述待法务审核）：

- **本产品**：由乙方交付的、以 Docker 镜像与 docker compose 形态提供的 AI 工作助手，
  采用 Vue3 前端与 Express 后端单端口架构，运行于 Node 22，使用 SQLite（WAL 模式）存储。
- **私有化部署**：本产品部署在甲方自有服务器与客户内网环境中，数据统一存放于甲方
  单一数据卷（部署时由 `APP_DATA_DIR` 指向，容器路径为 `/app/data`）。
- **数据卷**：存放 `app.db`、`images/`、`uploads/`、`vector-index/`、`backups/`、`logs/`
  的单一卷。
- **授权坐席 / 部署实例**：甲方获准使用本产品的用户账号数量上限与部署实例数量上限，
  分别为 `{{授权坐席数}}` 与 `{{部署实例数}}`，授权部署环境为 `{{授权部署环境}}`。
- **客户数据**：甲方及其终端用户上传、录入、生成的全部内容，包括账号信息、会话与提问、
  简历 / 文档 / 图片附件、知识库语料、审计日志、用量记录及备份文件。
- **模型输出**：本产品调用第三方大语言模型（当前为 DeepSeek，见隐私政策与 DPA）
  生成的回答、评分、匹配结果与摘要。
- **全局管理员**：部署时由环境变量引导创建的最高权限账号，可查看全库用户与审计日志。
- **子处理者**：为完成模型推理而接收提示词与文档片段的第三方服务方（见 DPA）。

## 第三条　账号与管理员责任

3.1 初始全局管理员账号由部署时的环境变量引导创建（变量名 `ADMIN_USERNAME` /
`ADMIN_PASSWORD`），其凭据由甲方在部署阶段自行设定并保管。甲方应：
首次登录后立即修改初始口令、妥善保管凭据、按最小权限原则分配账号，
并对该账号下发生的全部操作承担责任。

3.2 **甲方须知的技术事实**：该全局管理员账号的口令在**每次服务启动时会被同步为
环境变量中的取值**；甲方在后台修改口令后，必须同步更新环境变量并重启服务，
否则后台修改会在下次启动时被覆盖。甲方应将此同步要求纳入其运维流程。

3.3 当前版本为**开放自助注册**，甲方可在管理页面停用账号、设置按用户日配额。
甲方应自行决定注册准入策略并对账号实名、权限分配与停用操作负责。

3.4 **已知能力边界（如实披露，待甲方书面确认）**：当前版本**无 SSO**、**无多租户**、
**无自动化的「删除用户全部数据」接口**（需人工按运维流程处理）、
**无数据留存自动清理定时任务**、**无异地备份**（备份位于甲方同一数据卷内，
需甲方自行外送到异地）。上述缺口是否可接受、是否需要补充约定，由双方确认，
相关表述待法务审核。

## 第五条　AI 生成内容的性质

5.1 本产品中的回答、摘要、评分、匹配结果等由人工智能模型生成，
**仅为辅助建议与参考信息**，乙方**不保证**其准确性、完整性、时效性、
无偏见、无侵权或适用于特定目的。

5.2 甲方及终端用户**必须对模型输出进行人工复核**后再行使用，
不得将模型输出作为唯一依据或直接据以作出对他人权益有实质影响的决定。

5.3 模型输出**不构成**录用或淘汰决定、法律意见、医疗诊断、投资建议、
资质认定或其他需要由具备相应资质的专业人员作出的判断。

5.4 本产品的**简历文本与用户提问会发送给第三方模型厂商 DeepSeek 用于生成回答**；
甲方可自行配置其 API Key，未来亦可替换为本地模型。embedding 与向量检索
（本地 bge-small-zh-v1.5 模型 + 本地向量索引）**完全在甲方内网本地完成，不上传**。
上述数据流向的完整告知见 `隐私政策.md` 与 `数据处理协议-DPA.md`。

5.5 模型输出的权利归属与使用边界、以及乙方是否对其主张权利，
**由双方另行约定并经法务审核**，本协议不作确定性认定。
